# Week 1 Biomedical Signal Processing Project

## Objective

用 2～4 句话解释：
这个项目想解决什么问题？

## Simulated Signal

写清楚：
- sampling rate
- duration
- clean signal
- interference
- random noise

## Processing Pipeline

描述：

signal generation
→ measured signal
→ statistics
→ threshold analysis
→ moving average
→ evaluation
→ visualization

## Evaluation

解释：
Measured MAE 和 Filtered MAE 是什么。
你的 filtering 有没有改善。

## Results

写你这次运行的大致结果，例如：

Measured MAE ≈ ...
Filtered MAE ≈ ...
Measured error std ≈ ...
Filtered error std ≈ ...

不要要求每次随机运行数字完全一样。

## Limitations

至少写出两个限制。

例如思考：
真实 biomedical signal 是否是 sine wave？
真实数据有没有 clean ground truth？
moving average 是否可能破坏有用信息？

## Skills Used

写出这周实际使用的技术。
